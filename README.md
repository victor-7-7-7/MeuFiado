# MeuFiado

Sistema de gestão comercial voltado à rotina de pequenos negócios. O projeto reúne controle de fiado, vendas, estoque, caixa, fornecedores e relatórios.

## Objetivo

Centralizar informações da operação e facilitar o acompanhamento de vendas e valores a receber.

## Tecnologias

Python e Flask, com interface web. O projeto segue em evolução.

## Conteúdo deste repositório

Esta versão contém o pacote [`Meufiado-github.zip`](./Meufiado-github.zip). O código ainda está compactado; extraia o arquivo para consultar sua estrutura e as instruções disponíveis dentro do pacote.

A estrutura interna e os requisitos de execução precisam ser conferidos após a extração. Esta apresentação não representa uma validação de todas as funcionalidades do pacote.

## Próxima melhoria de organização

Disponibilizar os arquivos de código diretamente no repositório permitirá navegar pelos módulos, acompanhar alterações e revisar o projeto sem baixar um ZIP.
